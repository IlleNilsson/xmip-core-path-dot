# xmip-core-path-dot

Dot path technology: the Xmip content selector — names, ordinals, keys and the
streaming wildcard — read and written over a JSON Stream, for promote, demote,
route and process. A technology of
[xmip-core-path](https://github.com/IlleNilsson/xmip-core-path).

## Toolchain

`rust-toolchain.toml` pins the toolchain for the whole estate. Do not change it
here.

## Verification

The included workflow is manual-only and calls the versioned shared workflow at
`IlleNilsson/.github@v1`.
